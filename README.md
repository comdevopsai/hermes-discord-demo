# Hermes Discord publishing demonstration

Public demonstration content only. A buildless website for GitHub Pages, published from the root of `main`. Open `index.html` through a static HTTP server to preview it.

The workflow uses a reviewed draft pull request, approval of its exact revision, and verification of the deployed commit and live file bytes. Descriptions of presentation and content-pack workflows are illustrative; acceptance evidence is maintained separately.

No credentials, private documents, external fonts, analytics, or package installation are required by this website.
